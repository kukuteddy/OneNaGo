# 玩哪走 OneNaGo 品牌規範

| 項目 | 內容 |
|---|---|
| 中文名稱 | 玩哪走 |
| 英文名稱（App 名稱、網址、程式內部） | **OneNaGo** |
| 標語 | 台灣在地生活指南 |

## 顏色

| Token | 色碼 | 用途 |
|---|---|---|
| `--brand` | `#FF6827` | 品牌橘：Logo、主要按鈕、選中狀態 |
| `--brand-dark-mode` | `#FF7A45` | 深色模式下的品牌橘（提高對比） |
| `--paper` | `#FEFDF9` | 暖白：Logo 白色部分、淺色底 |
| `--ink` | `#222222` | 文字、中文字標 |

橘色是從原始圖檔取樣的平均值。

## 檔案

| 檔案 | 用途 |
|---|---|
| `app-icon.svg` | App 圖示、網站 favicon（向量，任何尺寸都清晰） |
| `logo-pin.svg` | 淺色底用的圖標（橘框白底＋橘色笑臉） |
| `source/app-icon.jpg` | 原始 App 圖示（2048×2048） |
| `source/logo-horizontal.jpg` | 原始橫式 Logo（圖示＋玩哪走＋OneNaGo） |
| `source/banner-hero.jpg` | 原始品牌主視覺（含騎樓街景照片） |

SVG 是依原圖重繪的近似版，比例和角度與原圖一致。`source/` 裡的 JPG 是 AI 生成的原稿，「哪」字的部分筆畫有模糊。正式印刷或上架前，建議請設計師依原稿出一份正式向量檔（字標要用實際字型重排）。

## 使用規則

- 圖標的大頭針固定**向左下傾斜**，笑臉的左眼比右眼高。
- 圖標放在橘底時，大頭針用白色；放在白底時，用「橘框＋橘色笑臉」的版本。
- 中文字標用粗黑體，英文 OneNaGo 用幾何無襯線體（字母 N、G 大寫）。
- 網站自動產生的素材（PWA 圖示、首頁主視覺）由 `pipeline.py` 從這個資料夾產生，不要手動改 `data/` 裡的副本。
